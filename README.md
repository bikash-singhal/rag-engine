# RAG Engine

A production-style Retrieval-Augmented Generation (RAG) engine built from scratch in Python.

## Features
- PDF ingestion
- Text chunking
- Embedding generation
- FAISS vector search
- Retrieval pipeline
- LLM integration
- Modular architecture

## Tech Stack
- Python
- FAISS
- Sentence Transformers
- Amazon Bedrock (planned)
